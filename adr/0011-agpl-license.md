# ADR-0011: VOT uses AGPL-3.0-only

- Status: Accepted
- Date: 2026-07-31
- Decision owner: David Torcivia

## Decision

VOT source code and project documentation are licensed under the GNU Affero
General Public License version 3 only, identified by SPDX expression
`AGPL-3.0-only`.

The complete license text is stored in `LICENSE`. Source distributions retain
that file and the project notice. Dependency licenses remain their own and must
pass the dependency policy.

## Consequences

Modified versions offered to users over a network must provide corresponding
source as required by section 13 of the license. Contributions are accepted
under AGPL-3.0-only. Proprietary source and incompatible dependencies are not
accepted.
