# Security Policy

VOT is pre-alpha. No released version currently receives production security
support.

Please report suspected vulnerabilities privately through the repository host's
security-advisory facility. Do not include unpublished media, credentials,
capability tokens, private keys, raw workflow paths, or customer identifiers in
a public issue or trace attachment.

A useful report includes the affected commit, platform, minimal synthetic
reproduction, expected invariant, actual behavior, and whether publication or an
assurance receipt was incorrectly possible. Redact traces according to
`spec/telemetry.md`.

The project will acknowledge a report, establish a private remediation plan,
and coordinate disclosure after a fix and regression test are available. This
policy creates no guarantee of response time during pre-alpha development.
