# Security Policy

VOT is pre-alpha. No released version receives production security support.

## Reporting

Report suspected vulnerabilities privately through the repository host's
security-advisory facility.

Do not include credentials, private keys, capability tokens, raw workflow paths,
or customer identifiers in public issues or trace attachments. Redact traces
per `spec/telemetry.md`.

A useful report includes: affected commit, platform, minimal synthetic
reproduction, expected invariant, actual behavior, and whether publication or
an assurance receipt was incorrectly possible.

## Process

The project will acknowledge a report, establish a private remediation plan,
and coordinate disclosure after a fix and regression test are available. No
guaranteed response time during pre-alpha.
