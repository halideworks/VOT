# VOT Datagram FEC Erasure Code v0

Status: normative for the experimental `DATAGRAM_FEC` extension. Disabled by
default. This document defines the erasure code only: the field, the generator
matrix, systematic encoding, and erasure decoding. Frame payloads, credit, and
generation lifecycle are specified separately when the wire integration lands.

## 1. Field

The code operates over GF(2^8). Elements are bytes. Addition is XOR.
Multiplication is polynomial multiplication modulo the primitive polynomial

```text
x^8 + x^4 + x^3 + x^2 + 1    (0x11D)
```

with generator element `0x02`, so `exp[i] = 2^i` for `i` in `0..255` and
`exp[255] = exp[0] = 1`. Every non-zero element `a` has `inverse(a) =
exp[255 - log(a)]`. This is the field of RFC 5510 section 8.1 and RFC 6865.

## 2. Geometry

A coding geometry is the triple `(k, r, L)`:

| Field | Meaning | Range |
|---|---|---:|
| `k` | source symbol count | `1..=64` |
| `r` | repair symbol count | `0..=16` |
| `L` | symbol length in bytes | `1..=65535` |

Values outside these ranges are `INVALID_GEOMETRY`. The `k` and `r` caps are
the frozen v0.3 constants (architecture section 9). A profile that carries
symbols in QUIC datagrams MUST choose `L` at or below the datagram payload the
path allows; the code itself does not depend on `L`.

Every symbol in one generation has exactly `L` bytes. Padding of a short final
source symbol is the caller's responsibility and is outside the code.

## 3. Encoding symbol identifiers

Symbols are numbered by an encoding symbol identifier (ESI). Source symbols
are ESIs `0..k-1` in data order. Repair symbols are ESIs `k..k+r-1`. The code
is systematic: source symbols are transmitted unchanged.

## 4. Generator matrix

Repair symbol `i` (for `i` in `0..r`) is the GF(2^8) linear combination of the
source symbols with the coefficient row

```text
G[i][j] = inverse((k + i) XOR j)      for j in 0..k
```

This is a Cauchy matrix with `x_i = k + i` and `y_j = j`. Because `x_i` and
`y_j` never coincide (`k + i >= k > j`) every entry is defined, and because the
sets are disjoint every square submatrix of `G` is invertible. Consequently
the stacked matrix `[I_k; G]` has the property that any `k` of its `k + r` rows
form an invertible matrix, and any `k` received symbols reconstruct all `k`
source symbols.

An encoder given other than `k` source symbols, or a source symbol whose
length is not `L`, returns `INVALID_SYMBOL` and produces nothing.

Repair byte `p` of repair symbol `i` is

```text
repair[i][p] = XOR over j in 0..k of  G[i][j] * source[j][p]
```

## 5. Decoding

Given the received symbols of one generation, the decoder:

1. Returns `INVALID_SYMBOL` if any received ESI is at or above `k + r`, any
   received symbol's length is not `L`, or one ESI is presented twice. The
   whole call fails; no symbol is dropped and decoding does not continue.
2. If fewer than `k` distinct ESIs are present, returns
   `INSUFFICIENT_SYMBOLS`. Nothing is reconstructed.
3. Selects exactly `k` rows: every received source ESI, then the received
   repair ESIs in ascending order until `k` rows are chosen.
4. Solves the `k x k` system by Gauss-Jordan elimination over GF(2^8) with the
   received symbol bytes as the right-hand side, yielding all `k` source
   symbols.

Step 3 makes the decoder deterministic; implementations MAY skip elimination
entirely when all `k` source ESIs were received. The result never depends on
which repair symbols were chosen because every selection is invertible and the
system has one solution.

## 6. Bounds

The decoder allocates for at most `k` symbols of `L` bytes and one `k x k`
coefficient matrix, all bounded by the caps above before any allocation. It
never allocates from an untrusted count that has not been checked against the
geometry.

## 7. Test vectors

`test-vectors/fec/vectors.json` is generated by
`tools/validate_fec_vectors.py`, an independent implementation of this text.
The file carries field spot checks (exp and log tables, products, inverses),
generator rows and matrix digests, encode cases with the repair bytes and the
digest of the reconstruction after erasing the listed ESIs, insufficient cases
that MUST return `INSUFFICIENT_SYMBOLS`, invalid symbol cases that MUST return
`INVALID_SYMBOL` even though `k` valid symbols are present, and geometries
that MUST return `INVALID_GEOMETRY`. Source symbol `esi` byte `i` in a vector is
`(i*17 + esi*7 + 3) % 251`.
